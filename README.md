# portofren

Renaldy Bilal Setyawan's portfolio, live at <https://renalazy.github.io/portofren/>.

A Next.js static export with a hand-drawn sketchbook look: graph paper, tape,
sticky notes and spring animations. Content is bilingual (EN/ID).

## Run it

```bash
npm install
npm run dev     # http://localhost:3000/portofren
npm run build   # static site in out/
```

## Where things live

| Path | What |
|---|---|
| `lib/content.ts`, `lib/site.ts` | All homepage copy, projects, experience and credentials (EN/ID) |
| `components/` | Homepage sections; `components/case/` holds the case-study pages and their shared kit |
| `app/projects/*/page.tsx` | Case-study routes |
| `public/certificates/` | Certificate images and PDFs shown in the viewer |
| `public/projects/notebooks/` | Rendered Jupyter notebooks, generated by `tools/build_notebooks.py` |
| `public/projects/*.html` | Redirects from the old `.html` case-study URLs |

To show or hide a project on the homepage, flip its `featured` flag in `lib/content.ts`.

## Deploy

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site and
publishes `out/` to GitHub Pages.
